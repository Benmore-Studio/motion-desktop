# Motion Desktop

Your AI Rolodex, on your Mac. Two panes: an agent you talk to (Claude Agent SDK → Motion's MCP), and your live context database (contacts, timelines, follow-up queue).

## Run from source
```sh
npm install
npm start
```
Sign in with Google (Motion OAuth), paste an Anthropic API key (BYOK), and talk to your Rolodex. Platform-credit and Claude Code subscription engines are on the roadmap.
